Everything is already set up.

  
No weekend of dotfile hunting. A fresh install looks and works like a daily driver.

  

    
Floating glass bar
Waybar built as separate glass capsules: workspaces, window title, network speed, CPU, RAM, volume, clock and tray.

    
Prayer times in the bar
A built-in script computes the next prayer for Cairo time. Hover to see all five times in a tooltip. Built for Arabic-speaking users, not bolted on.

    
Arabic + English, instantly
Switch layouts with Alt + Shift. RTL text renders correctly across the desktop.

    
Wallpaper drives the colors
Change the wallpaper and pywal repaints Waybar and Kitty automatically.

    
Dev stack included
VS Code, Node, PNPM, Bun, Rust, Go, Docker, lazygit, ripgrep, fzf, zoxide and Starship are ready on first boot.

    
Smooth even in a VM
Hyprland is tuned for VirtualBox, with no broken cursor and no flicker.

    
Lock screen and login to match
Hyprlock with glass blur, and an SDDM login with four themes you can switch from the terminal.

  






  

    
Two desktops. Pick your style.

    
Choose at the login screen. Both share the same look and the same shortcuts where possible.

  

  

    
Hyprland
Tiling, keyboard-first, transparent rounded windows with zero borders. Fast and minimal.
  • Rofi launcher and Waybar
  • Hyprlock lock screen
  • Workspaces 1–5

    
KDE Plasma 6
Classic and mouse-friendly on Wayland, with Breeze Dark and Papirus icons.
  • Dolphin, Ark, Spectacle
  • System Monitor, KCalc
  • Branded as ARise Linux

  






  
Four themes. One command.

  
Run arise-theme and Hyprland and Plasma change together. Try it here, this page re-themes too.

  

    
    
    
    
  






  
Commands that ship with the system.

  

    
arise-theme
Switch between 4 themes across Hyprland and KDE.

    
arise-update
Update keys, pacman and AUR packages, then clean the cache.

    
arise-setup
Install gaming, developer or video-editing bundles, or run a health check.

    
sddm-switcher
Change the login theme and sync wallpaper and colors.

    
change-wallpaper.sh
Smooth wallpaper change, then pywal repaints the UI.

    
system-help
Interactive shortcut guide. Press Super + H.

System Requirements

  
Everything you need to run ARise Linux, with extra headroom for demanding workflows.

  

    

      
Minimum Requirements

      
    
        
  • Processor: 64-bit dual-core, 2.0 GHz or faster
    • 
        
  • Memory: 4 GB RAM
    • 
        
  • Storage: 25 GB available space
    • 
        
  • Graphics: OpenGL 3.3+ or Vulkan-capable GPU (Intel HD 4000, AMD, or NVIDIA)
    • 
        
  • Boot: UEFI mode
    • 
      

    

    

      
Recommended for Developers & Power Users

      
    
        
  • Processor: 64-bit quad-core (Intel Core i5 or AMD Ryzen 5)
    • 
        
  • Memory: 8–16 GB RAM for Docker, Rust, and heavy workflows
    • 
        
  • Storage: 60 GB+ fast SSD, with room for Timeshift snapshots
    • 
        
  • Graphics: Modern dedicated or integrated GPU for smooth 60+ FPS Wayland animations
    • 
        
  • Display: 1080p or higher
    •
